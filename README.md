
# FlyRank CRUD Practice - FastAPI Task API

This project is a database-backed CRUD REST API built with **FastAPI** and **SQLite** as part of backend engineering practice tasks. It provides core task management capabilities, input validation via Pydantic, and automatic interactive documentation.

## Features

- **Root & Health Check:** System status monitoring (`/health`) and API metadata overview (`/`).
- **Full CRUD Operations (SQLite-backed):**
  - `GET /tasks` - Retrieve all tasks from the database.
  - `GET /tasks/{id}` - Retrieve a specific task by its ID.
  - `POST /tasks` - Create a new task (with payload validation).
  - `PUT /tasks/{id}` - Update an existing task's title or completion status.
  - `DELETE /tasks/{id}` - Remove a task by ID.
- **Persistence & Auto-Setup:** Data is stored locally in `tasks.db`[cite: 2]. The database file and table are created automatically on the first run, and initial tasks are seeded only if the table is empty[cite: 2].
- **Interactive Documentation:** Automatic Swagger UI (`/docs`) generated by FastAPI[cite: 1, 2].

## Tech Stack & Database Choice

- **Python** (3.10+)[cite: 2]
- **FastAPI** (Modern, fast web framework for building APIs)[cite: 2]
- **SQLite** (Chosen because it is a single file, requires zero configuration, and ensures data survives server restarts)[cite: 2]

## Getting Started & Installation

> **Note on Database Storage:** The database file (`tasks.db`) is created automatically when you first run the server[cite: 2]. It is typically ignored by Git so that each clean clone starts fresh[cite: 2].

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd flyrank-crud-practice

```

2. **Create and activate a virtual environment:**
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

```


3. **Install dependencies:**
```bash
pip install fastapi uvicorn pydantic

```


4. **Run the development server (One command to start):**
```bash
uvicorn main:app --reload

```


(This single command automatically spins up the server, creates `tasks.db`, builds the table, and seeds the 3 initial tasks if the table is empty.)


5. **Access the API:**
* Open your browser and navigate to: `http://127.0.0.1:8000`
* Interactive Swagger UI documentation: `http://127.0.0.1:8000/docs`

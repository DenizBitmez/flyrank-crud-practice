# FlyRank CRUD Practice - FastAPI Task API

This project is a minimalist, in-memory CRUD REST API built with **FastAPI** as part of backend engineering practice tasks. It provides core task management capabilities, input validation via Pydantic, and automatic interactive documentation.

## Features

- **Root & Health Check:** System status monitoring (`/health`) and API metadata overview (`/`).
- **In-Memory CRUD Operations:**
  - `GET /tasks` - Retrieve all tasks.
  - `GET /tasks/{id}` - Retrieve a specific task by its ID.
  - `POST /tasks` - Create a new task (with payload validation).
  - `PUT /tasks/{id}` - Update an existing task's title or completion status.
  - `DELETE /tasks/{id}` - Remove a task by ID.
- **Interactive Documentation:** Automatic Swagger UI (`/docs`) and ReDoc (`/redoc`) generated by FastAPI.

---

## Tech Stack

- **Python** (3.10+)
- **FastAPI** (Modern, fast web framework for building APIs)
- **Uvicorn** (Lightning-fast ASGI server)
- **Pydantic** (Data validation and settings management)

## Getting Started & Installation

Follow these steps to run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd flyrank-crud-practice

```

2. **Create and activate a virtual environment:**
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

```


3. **Install dependencies:**
```bash
pip install fastapi uvicorn pydantic

```

4. **SQL by Hand - Example Query**
I used DB Browser for SQLite to interact with the database directly.
```bash
SELECT COUNT(*) FROM tasks;

```
Result Description: This query returned the total count of rows present in the tasks table (e.g., 3), confirming the persistence of the seeded data.


5. **Run the development server:**
```bash
uvicorn main:app --reload

```


6. **Access the API:**
* Open your browser and navigate to: `http://127.0.0.1:8000`
* Interactive Swagger UI documentation: `http://127.0.0.1:8000/docs`
